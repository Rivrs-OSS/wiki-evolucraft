# 🏛️ Les Portails de Donjons

{% embed url="https://www.youtube.com/watch?index=3&list=PL1QLnkRl9WVyR0eGUtFoTo8a9MBJHBFwa&v=NtB-gvzz8mE" %}
**Tuto : Les Nouveautés MMO/RPG d'Evolucraft**
{% endembed %}

Les donjons sont une nouvelle fonctionnalité sur Evolucraft, offrant des aventures passionnantes aux explorateurs en quête d'action pour monter en niveaux de classe, gagner de nouvelles armes de classe ou encore obtenir de nombreuses autres récompenses !

{% hint style="info" %}
Nous vous invitons, si besoin, à relire la page de présentation des donjons sur le serveur : **🏛️ [Les Donjons](https://wiki.evolucraft.fr/le-gameplay/les-donjons)**
{% endhint %}

## <mark style="color:green;">💠 Comment différencier un portail de donjon selon sa rareté ? 🔍</mark>

Pour reconnaître à quel type appartient le donjon, vous avez <mark style="color:green;">plusieurs indices</mark> visibles dessus. Il y a notamment <mark style="color:green;">la couleur des vitres du portail</mark> mais aussi la <mark style="color:green;">taille du portail</mark> : plus il est grand, plus il demandera un niveau de classe élevé pour le réaliser.

### 🔸 Les donjons classiques

* 🟩 [<mark style="color:green;">Commun</mark>](https://wiki.evolucraft.fr/codex/donjons/commun) : _(Niveau requis : <mark style="color:green;">niveau 1</mark>)_
* 🟨 [<mark style="color:yellow;">Rare</mark>](https://wiki.evolucraft.fr/codex/donjons/rare) : _(Niveau requis : <mark style="color:yellow;">niveau 10</mark>)_
* 🟦 [<mark style="color:blue;">Épique</mark>](https://wiki.evolucraft.fr/codex/donjons/epique) : _(Niveau requis : <mark style="color:blue;">niveau 25</mark>)_
* 🟪 [<mark style="color:purple;">Légendaire</mark>](https://wiki.evolucraft.fr/codex/donjons/legendaire) : _(Niveau requis : <mark style="color:purple;">niveau 40</mark>)_
* 🟥 [<mark style="color:red;">Mythique</mark>](https://wiki.evolucraft.fr/codex/donjons/mythique) : _(Niveau requis : <mark style="color:red;">niveau 50</mark>)_

{% hint style="info" %}
REMARQUE 🤓☝ : Plus un donjon demande un niveau élevé, plus il est difficile, mais les récompenses sont également plus importantes !
{% endhint %}

Pour rendre votre expérience variée, plusieurs types de biomes de donjons sont présents, modifiant les salles, les monstres ainsi que l'apparence du portail. Vous pourrez trouver des donjons dans les biomes suivants :

* **Forêt** 🌳
* **Jungle** 🦜
* **Marais** 🐸
* **Neige** ❄️
* **Désert** 🏜️
* **Messa** 🌵
* **Savane** 🦏
* **Nether** 🔥
