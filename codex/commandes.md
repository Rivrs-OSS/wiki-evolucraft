# 📑 Commandes

Retrouvez ici toutes les informations concernant les commandes disponibles sur le serveur.

{% hint style="info" %}
`[...]` signifie que le paramètre est obligatoire.

`<...>` signifie que vous pouvez saisir une chaîne de caractères avec des espaces.

`{...}` signifie que le paramètre est optionnel.
{% endhint %}

<details>

<summary>🏠 Commandes générales</summary>

* <mark style="color:green;">`/menu`</mark> : Ouvre le menu général.
* <mark style="color:green;">`/reglement`</mark> : Donne un lien vers les règles du serveur.
* <mark style="color:green;">`/discord`</mark> : Donne un lien vers le Discord du serveur.
* <mark style="color:green;">`/site`</mark> : Fournit un lien vers le site web du serveur.
* <mark style="color:green;">`/vote`</mark> : Ouvre le menu concernant les votes pour le serveur.
* <mark style="color:green;">`/wiki`</mark> : Donne un lien vers le wiki du serveur.
* <mark style="color:green;">`/ping`</mark> : Vérifie la latence entre le joueur et le serveur.
* <mark style="color:green;">`/whereiam`</mark> : Indique le monde et la zone où vous vous trouvez.
* <mark style="color:green;">`/abo`</mark> : Gère les avantages de l'abonnement premium (uniquement pour ceux qui l'ont acheté).

</details>

<details>

<summary>🌍 Mondes</summary>

* <mark style="color:green;">`/spawn`</mark> : Permet de vous téléporter au spawn du serveur.
* <mark style="color:green;">`/monde`</mark> : Permet d’ouvrir le menu des différents mondes du serveur.
* <mark style="color:green;">`/codex`</mark> : Permet de vous téléporter aux différentes zones dans le spawn du serveur.
* <mark style="color:green;">`/newworld`</mark> : Permet de vous téléporter dans la zone du New World.
* <mark style="color:green;">`/events`</mark> : Permet de se téléporter dans le monde des événements organisés par les animateurs.
* <mark style="color:green;">`/rtp`</mark> : Permet de se téléporter aléatoirement dans le monde où vous êtes actuellement.

</details>

<details>

<summary>📈 Progression</summary>

* <mark style="color:green;">`/rangs`</mark> : Affiche les différents rangs disponibles.
* <mark style="color:green;">`/classe`</mark> : Affiche la liste des classes.
* <mark style="color:green;">`/jobs`</mark> : Affiche la liste des métiers.
* <mark style="color:green;">`/pass`</mark> : Affiche le menu du Pass du serveur.
* <mark style="color:green;">`/classement`</mark> : Affiche le classement général de diverses statistiques.
* <mark style="color:green;">`/quest`</mark> : Affiche les différentes récompenses disponibles dans les parchemins.
* <mark style="color:green;">`/collection`</mark> : Affiche les différentes collections présentes sur le serveur.
* <mark style="color:green;">`/rewards`</mark> : Accorde des récompenses journalières en fonction du temps de jeu de la journée.
* <mark style="color:green;">`/vote`</mark> : Affiche les liens de vote, le classement et les récompenses du palier de vote hebdomadaire.

</details>

<details>

<summary>🧭 Points de téléportation</summary>

* <mark style="color:green;">`/sethome [Nom]`</mark> : Ajoute un point de téléportation à votre position actuelle.
* <mark style="color:green;">`/home [Nom]`</mark> : Permet de se téléporter au point sauvegardé sous le nom indiqué.
* <mark style="color:green;">`/delhome [Nom]`</mark> : Supprime le point de téléportation portant le nom indiqué.
* <mark style="color:green;">`/back`</mark> : Permet de retourner à la position précédente dans le monde.
* <mark style="color:green;">`/tpa [Pseudo]`</mark> : Permet d'envoyer une demande de téléportation à l'emplacement du joueur indiqué.
* <mark style="color:green;">`/tpahere [Pseudo]`</mark> : Permet d'envoyer à un joueur une demande de téléportation vers votre emplacement.
* <mark style="color:green;">`/tpyes [Pseudo]`</mark> : Permet d'accepter la demande de téléportation du joueur indiqué.
* <mark style="color:green;">`/tpdeny [Pseudo]`</mark> : Permet de refuser la demande de téléportation du joueur indiqué.

</details>

<details>

<summary>💰 Commerce et économie</summary>

* <mark style="color:green;">`/money`</mark> : Affiche le montant d'argent que vous possédez.
* <mark style="color:green;">`/boutique`</mark> : Affiche la boutique, les offres du jour et les autres achats disponibles contre des gemmes.
* <mark style="color:green;">`/pub`</mark> : Permet de consulter les différentes publicités des joueurs.
* <mark style="color:green;">`/trade [Pseudo]`</mark> : Permet de réaliser un échange avec un joueur proche de vous.
* <mark style="color:green;">`/pay [Pseudo] [Montant]`</mark> : Permet de payer un joueur.
* <mark style="color:green;">`/shop`</mark> : Permet de vous téléporter à la zone marchande du spawn.
* <mark style="color:green;">`/sell hand`</mark> : Permet de vendre l'objet tenu en main au prix du marchand au spawn.
* <mark style="color:green;">`/sell all`</mark> : Permet de vendre tous les objets vendables de votre inventaire au prix du marchand du spawn.
* <mark style="color:green;">`/copper_exchange`</mark> : Permet d'échanger les différentes variantes de blocs de cuivre.
* <mark style="color:green;">`/dragon`</mark> : Permet d'échanger des objets obtenus soit dans les donjons, soit dans l'End.
* <mark style="color:green;">`/enchere`</mark> : Permet de vous téléporter à la zone des enchères.
* <mark style="color:green;">`/encherejoin`</mark> : Permet de rejoindre l'événement des enchères.
* <mark style="color:green;">`/enchereclaim`</mark> : Permet de récupérer vos récompenses des enchères.

</details>

<summary>🛒 Hôtel de vente</summary>

* <mark style="color:green;">`/ah`</mark> ou <mark style="color:green;">`/hdv`</mark> : Permet de voir les offres de vente temporaires des joueurs.
* <mark style="color:green;">`/ah sell [Prix] {Quantité}`</mark> : Permet de proposer un objet à la vente en définissant son prix et sa quantité.
* <mark style="color:green;">`/ah average`</mark> : Permet de voir le prix moyen de l'objet tenu en main.
* <mark style="color:green;">`/ah search inname:[Nom de l'item]`</mark> : Permet de rechercher les offres portant sur un objet ayant le même nom.
* <mark style="color:green;">`/ah search material:[ID de l'item]`</mark> : Permet de rechercher les offres portant sur un objet ayant le même identifiant.
* <mark style="color:green;">`/ah search seller:[Pseudo]`</mark> : Permet de voir les offres du joueur concerné.
* <mark style="color:green;">`/ah history`</mark> : Permet de voir l'historique des ventes et des achats réalisés sur les 15 derniers jours.

</details>

<summary>👷 Métiers (Jobs)</summary>

* <mark style="color:green;">`/jobs`</mark> : Permet d'afficher le menu des métiers.
* <mark style="color:green;">`/jobs join [Métier]`</mark> : Permet de rejoindre un métier.
* <mark style="color:green;">`/jobs leave [Métier]`</mark> : Permet de quitter un métier.
* <mark style="color:green;">`/jobs claim [Métier]`</mark> : Permet de récupérer les récompenses du métier (faites attention à avoir suffisamment de place dans votre inventaire).
* <mark style="color:green;">`/jobs info [Métier]`</mark> : Permet de connaître les actions faisant gagner de l'expérience dans un métier.
* <mark style="color:green;">`/jobs bonus [Métier]`</mark> : Permet de voir les bonus appliqués à un métier par les compagnons, les boosters et les événements.
* <mark style="color:green;">`/jobs stats [Pseudo]`</mark> : Permet de voir les statistiques des métiers d'un joueur.

</details>

<summary>🏙️ Villes</summary>

* <mark style="color:green;">`/pays`</mark> : Permet d’ouvrir le menu des différents pays disponibles pour la création de votre ville.
* <mark style="color:green;">`/ville`</mark> ou <mark style="color:green;">`/v`</mark> : Permet d’ouvrir le menu de la ville.
* <mark style="color:green;">`/v create [Nom de la ville]`</mark> : Permet de créer votre ville.
* <mark style="color:green;">`/v claim`</mark> : Permet d'agrandir votre ville.
* <mark style="color:green;">`/v autoclaim`</mark> : Permet d'agrandir automatiquement votre ville au fil de vos déplacements.
* <mark style="color:green;">`/v unclaim`</mark> : Permet de retirer de votre ville le chunk où vous vous trouvez.
* <mark style="color:green;">`/v spawn`</mark> ou <mark style="color:green;">`/v home`</mark> : Permet de vous téléporter au point de spawn de la ville.
* <mark style="color:green;">`/v setspawn`</mark> ou <mark style="color:green;">`/v sethome`</mark> : Permet de redéfinir le spawn de la ville.
* <mark style="color:green;">`/v add [Pseudo du joueur]`</mark> : Permet d'inviter un joueur dans votre ville.
* <mark style="color:green;">`/v info [Nom de la ville]`</mark> : Permet de voir les informations de la ville.
* <mark style="color:green;">`/v members`</mark> : Permet de voir les membres de la ville actuellement connectés.
* <mark style="color:green;">`/v bank deposit [Montant]`</mark> : Permet de déposer de l'argent dans la banque de la ville sélectionnée.
* <mark style="color:green;">`/v bank withdraw [Montant]`</mark> : Permet de retirer de l'argent de la banque de la ville sélectionnée.
* <mark style="color:green;">`/v chat <Message>`</mark> ou <mark style="color:green;">`!<Message>`</mark> : Permet d'envoyer ponctuellement un message dans le chat de votre ville.
* <mark style="color:green;">`/v chat toggle`</mark> : Permet d'utiliser le chat de votre ville jusqu'à sa désactivation.
* <mark style="color:green;">`/limites`</mark> : Affiche les limites de blocs dans les chunks d'une ville.
* <mark style="color:green;">`/v view`</mark> : Affiche la délimitation de votre ville.
* <mark style="color:green;">`/v setowner [Pseudo] --confirm`</mark> : Permet de transférer la fonction de maire à un autre joueur.
* <mark style="color:green;">`/v subarea create [Nom]`</mark> : Permet de créer une sous-zone à l'emplacement sélectionné.
* <mark style="color:green;">`/v subarea kick [Nom de la sous-zone] [Pseudo]`</mark> : Permet de retirer un joueur de la sous-zone.
* <mark style="color:green;">`/v subarea view`</mark> : Permet de voir les sous-zones dans la ville.
* <mark style="color:green;">`/v ban [Pseudo]`</mark> : Permet de bannir un joueur de votre ville.
* <mark style="color:green;">`/v unban [Pseudo]`</mark> : Permet de débannir un joueur de votre ville.
* <mark style="color:green;">`/v kick [Pseudo]`</mark> : Permet d'expulser un joueur de votre ville.
* <mark style="color:green;">`/v leave [Nom de la ville]`</mark> : Permet de quitter la ville indiquée.
* <mark style="color:green;">`/v disband --confirm`</mark> : Permet de supprimer votre ville définitivement.

</details>

* <mark style="color:green;">`/pwarp lock [Nom du Pwarp]`</mark> : Permet de verrouiller ou de déverrouiller l'accès à son PWarp.
* <mark style="color:green;">`/pwarp cost set [Nom du Pwarp] [Montant]`</mark> : Permet de modifier le prix d'entrée à la téléportation au PWarp.
* <mark style="color:green;">`/pwarp reset [Nom du Pwarp]`</mark> : Permet de modifier le point de spawn du PWarp.
* <mark style="color:green;">`/pwarp desc set [Nom du Pwarp] <Description du pwarp>`</mark> : Permet de modifier la description du PWarp sélectionné.
* <mark style="color:green;">`/pwarp rate [Nom du Pwarp] [Note de 1 à 5]`</mark> : Permet de noter le PWarp d'un joueur.
* <mark style="color:green;">`/pwarp info [Nom du Pwarp]`</mark> : Permet de voir les informations d'un PWarp sélectionné.
* <mark style="color:green;">`/pwarp list [Pseudo]`</mark> : Permet de voir les PWarps dont le joueur est propriétaire.
* <mark style="color:green;">`/pwarp ban set [Nom du Pwarp] [Pseudo]`</mark> : Permet de bannir un joueur du PWarp.
* <mark style="color:green;">`/pwarp ban remove [Nom du Pwarp] [Pseudo]`</mark> : Permet de débannir un joueur du PWarp.
* <mark style="color:green;">`/pwarp ban list [Nom du Pwarp]`</mark> : Permet de voir la liste des joueurs bannis du PWarp.
* <mark style="color:green;">`/pwarp setowner set [Nom du Pwarp] [Pseudo]`</mark> : Permet de transférer la propriété du PWarp.
* <mark style="color:green;">`/pwarp remove [Nom du Pwarp]`</mark> : Permet de supprimer le PWarp.

</details>

<summary>🏪 Shops de joueurs</summary>

* <mark style="color:green;">`/finditem [Acheter/Vendre] [ID de l'item/Nom de l'item]`</mark> : Permet de rechercher, dans le monde Construction, les coffres de joueurs qui achètent ou vendent l'objet souhaité.
* <mark style="color:green;">`/qs create [Prix]`</mark> : Permet de transformer le coffre visé en coffre de vente pour l'objet tenu en main.
* <mark style="color:green;">`/qs buy`</mark> : Permet de transformer le coffre de vente visé en coffre d'achat.
* <mark style="color:green;">`/qs price [Prix]`</mark> : Permet de changer le prix d'un coffre d'achat ou de vente.
* <mark style="color:green;">`/qs item`</mark> : Permet de changer l'objet proposé dans le coffre de vente ou d'achat.
* <mark style="color:green;">`/qs staff add [Pseudo]`</mark> : Permet d'ajouter un joueur dans la liste des joueurs pouvant modifier les informations du coffre.
* <mark style="color:green;">`/qs staff del [Pseudo]`</mark> : Permet de retirer un joueur de la liste des personnes pouvant modifier les informations du coffre.
* <mark style="color:green;">`/qs staff list`</mark> : Affiche la liste des joueurs pouvant modifier les informations du coffre.
* <mark style="color:green;">`/qs setowner [Pseudo]`</mark> : Permet de modifier le propriétaire du coffre de vente ou d'achat que vous regardez.
* <mark style="color:green;">`/qs history`</mark> : Permet de voir l'historique des ventes réalisées sur le coffre visé.
* <mark style="color:green;">`/qs remove`</mark> : Permet de supprimer le coffre de vente ou d'achat que vous regardez.

</details>
