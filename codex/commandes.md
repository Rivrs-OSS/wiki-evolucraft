# 📑 Commandes

Retrouvez ici toutes les informations concernant les commandes disponibles sur le serveur.

{% hint style="info" %}
`[...]` signifie que le paramètre est obligatoire.

`<...>` signifie que vous pouvez saisir une chaîne de caractères avec des espaces.

`{...}` signifie que le paramètre est optionnel.
{% endhint %}

<details>

<summary>🏠 Commandes générales</summary>

* `/menu` : Ouvre le menu général.
* `/reglement` : Donne un lien vers les règles du serveur.
* `/discord` : Donne un lien vers le Discord du serveur.
* `/site` : Fournit un lien vers le site web du serveur.
* `/vote` : Ouvre le menu concernant les votes pour le serveur.
* `/wiki` : Donne un lien vers le wiki du serveur.
* `/ping` : Vérifie la latence entre le joueur et le serveur.
* `/whereiam` : Indique le monde et la zone où vous vous trouvez.
* `/abo` : Gère les avantages de l'abonnement premium (uniquement pour ceux qui l'ont acheté).

</details>

<details>

<summary>🌍 Mondes</summary>

* `/spawn` : Permet de vous téléporter au spawn du serveur.
* `/monde` : Permet d’ouvrir le menu des différents mondes du serveur.
* `/codex` : Permet de vous téléporter aux différentes zones dans le spawn du serveur.
* `/newworld` : Permet de vous téléporter dans la zone du New World.
* `/events` : Permet de se téléporter dans le monde des événements organisés par les animateurs.
* `/rtp` : Permet de se téléporter aléatoirement dans le monde où vous êtes actuellement.

</details>

<details>

<summary>📈 Progression</summary>

* `/rangs` : Affiche les différents rangs disponibles.
* `/classe` : Affiche la liste des classes.
* `/jobs` : Affiche la liste des métiers.
* `/pass` : Affiche le menu du Pass du serveur.
* `/classement` : Affiche le classement général de diverses statistiques.
* `/quest` : Affiche les différentes récompenses disponibles dans les parchemins.
* `/collection` : Affiche les différentes collections présentes sur le serveur.
* `/rewards` : Accorde des récompenses journalières en fonction du temps de jeu de la journée.
* `/vote` : Affiche les liens de vote, le classement et les récompenses du palier de vote hebdomadaire.

</details>

<details>

<summary>🧭 Points de téléportation</summary>

* `/sethome [Nom]` : Ajoute un point de téléportation à votre position actuelle.
* `/home [Nom]` : Permet de se téléporter au point sauvegardé sous le nom indiqué.
* `/delhome [Nom]` : Supprime le point de téléportation portant le nom indiqué.
* `/back` : Permet de retourner à la position précédente dans le monde.
* `/tpa [Pseudo]` : Permet d'envoyer une demande de téléportation à l'emplacement du joueur indiqué.
* `/tpahere [Pseudo]` : Permet d'envoyer à un joueur une demande de téléportation vers votre emplacement.
* `/tpyes [Pseudo]` : Permet d'accepter la demande de téléportation du joueur indiqué.
* `/tpdeny [Pseudo]` : Permet de refuser la demande de téléportation du joueur indiqué.

</details>

<details>

<summary>💰 Commerce et économie</summary>

* `/money` : Affiche le montant d'argent que vous possédez.
* `/boutique` : Affiche la boutique, les offres du jour et les autres achats disponibles contre des gemmes.
* `/pub` : Permet de consulter les différentes publicités des joueurs.
* `/trade [Pseudo]` : Permet de réaliser un échange avec un joueur proche de vous.
* `/pay [Pseudo] [Montant]` : Permet de payer un joueur.
* `/shop` : Permet de vous téléporter à la zone marchande du spawn.
* `/sell hand` : Permet de vendre l'objet tenu en main au prix du marchand au spawn.
* `/sell all` : Permet de vendre tous les objets vendables de votre inventaire au prix du marchand du spawn.
* `/copper_exchange` : Permet d'échanger les différentes variantes de blocs de cuivre.
* `/dragon` : Permet d'échanger des objets obtenus soit dans les donjons, soit dans l'End.
* `/enchere` : Permet de vous téléporter à la zone des enchères.
* `/encherejoin` : Permet de rejoindre l'évènement des enchères.
* `/enchereclaim` : Permet de récupérer vos récompenses des enchères.

</details>

<details>

<summary>🛒 Hôtel de vente</summary>

* `/ah` ou `/hdv` : Permet de voir les offres de vente temporaires des joueurs.
* `/ah sell [Prix] {Quantité}` : Permet de proposer un objet à la vente en définissant son prix et sa quantité.
* `/ah average` : Permet de voir le prix moyen de l'objet tenu en main.
* `/ah search inname:[Nom de l'item]` : Permet de rechercher les offres portant sur un objet ayant le même nom.
* `/ah search material:[ID de l'item]` : Permet de rechercher les offres portant sur un objet ayant le même identifiant.
* `/ah search seller:[Pseudo]` : Permet de voir les offres du joueur concerné.
* `/ah history` : Permet de voir l'historique des ventes et des achats réalisés sur les 15 derniers jours.

</details>

<details>

<summary>⚔️ Classes</summary>

* `/classe` : Permet d'afficher le menu des classes.
* `/class` : Permet d'afficher votre classe sélectionnée.
* `/class stats [Pseudo]` : Permet de voir la progression des niveaux de chacune des classes du joueur.

</details>

<details>

<summary>👷 Métiers (Jobs)</summary>

* `/jobs` : Permet d'afficher le menu des métiers.
* `/jobs join [Métier]` : Permet de rejoindre un métier.
* `/jobs leave [Métier]` : Permet de quitter un métier.
* `/jobs claim [Métier]` : Permet de récupérer les récompenses du métier (faites attention à avoir suffisamment de place dans votre inventaire).
* `/jobs info [Métier]` : Permet de connaître les actions faisant gagner de l'expérience dans un métier.
* `/jobs bonus [Métier]` : Permet de voir les bonus appliqués à un métier par les compagnons, les boosters et les événements.
* `/jobs stats [Pseudo]` : Permet de voir les statistiques des métiers d'un joueur.

</details>

<details>

<summary>🏙️ Villes</summary>

* `/pays` : Permet d’ouvrir le menu des différents pays disponibles pour la création de votre ville.
* `/ville` ou `/v` : Permet d’ouvrir le menu de la ville.
* `/v create [Nom de la ville]` : Permet de créer votre ville.
* `/v claim` : Permet d'agrandir votre ville.
* `/v autoclaim` : Permet d'agrandir automatiquement votre ville au fil de vos déplacements.
* `/v unclaim` : Permet de retirer de votre ville le chunk où vous vous trouvez.
* `/v spawn` ou `/v home` : Permet de vous téléporter au point de spawn de la ville.
* `/v setspawn` ou `/v sethome` : Permet de redéfinir le spawn de la ville.
* `/v add [Pseudo du joueur]` : Permet d'inviter un joueur dans votre ville.
* `/v info [Nom de la ville]` : Permet de voir les informations de la ville.
* `/v members` : Permet de voir les membres de la ville actuellement connectés.
* `/v bank deposit [Montant]` : Permet de déposer de l'argent dans la banque de la ville sélectionnée.
* `/v bank withdraw [Montant]` : Permet de retirer de l'argent de la banque de la ville sélectionnée.
* `/v chat <Message>` ou `!<Message>` : Permet d'envoyer ponctuellement un message dans le chat de votre ville.
* `/v chat toggle` : Permet d'utiliser le chat de votre ville jusqu'à sa désactivation.
* `/limites` : Affiche les limites de blocs dans les chunks d'une ville.
* `/v view` : Affiche la délimitation de votre ville.
* `/v setowner [Pseudo] --confirm` : Permet de transférer la fonction de maire à un autre joueur.
* `/v subarea create [Nom]` : Permet de créer une sous-zone à l'emplacement sélectionné.
* `/v subarea kick [Nom de la sous-zone] [Pseudo]` : Permet de retirer un joueur de la sous-zone.
* `/v subarea view` : Permet de voir les sous-zones dans la ville.
* `/v ban [Pseudo]` : Permet de bannir un joueur de votre ville.
* `/v unban [Pseudo]` : Permet de débannir un joueur de votre ville.
* `/v kick [Pseudo]` : Permet d'expulser un joueur de votre ville.
* `/v leave [Nom de la ville]` : Permet de quitter la ville indiquée.
* `/v disband --confirm` : Permet de supprimer votre ville définitivement.

</details>

<details>

<summary>🚩 PWarps</summary>

* `/pwarp` : Affiche le menu des PWarps.
* `/pwarp create [Nom du Pwarp]` : Permet de créer un PWarp servant de point de téléportation aux autres joueurs.
* `/pwarp rename [Nom du Pwarp Actuel] [Nouveau nom du Pwarp]` : Permet de renommer son PWarp.
* `/pwarp lock [Nom du Pwarp]` : Permet de verrouiller ou de déverrouiller l'accès à son PWarp.
* `/pwarp cost set [Nom du Pwarp] [Montant]` : Permet de modifier le prix d'entrée à la téléportation au PWarp.
* `/pwarp reset [Nom du Pwarp]` : Permet de modifier le point de spawn du PWarp.
* `/pwarp desc set [Nom du Pwarp] <Description du pwarp>` : Permet de modifier la description du PWarp sélectionné.
* `/pwarp rate [Nom du Pwarp] [Note de 1 à 5]` : Permet de noter le PWarp d'un joueur.
* `/pwarp info [Nom du Pwarp]` : Permet de voir les informations d'un PWarp sélectionné.
* `/pwarp list [Pseudo]` : Permet de voir les PWarps dont le joueur est propriétaire.
* `/pwarp ban set [Nom du Pwarp] [Pseudo]` : Permet de bannir un joueur du PWarp.
* `/pwarp ban remove [Nom du Pwarp] [Pseudo]` : Permet de débannir un joueur du PWarp.
* `/pwarp ban list [Nom du Pwarp]` : Permet de voir la liste des joueurs bannis du PWarp.
* `/pwarp setowner set [Nom du Pwarp] [Pseudo]` : Permet de transférer la propriété du PWarp.
* `/pwarp remove [Nom du Pwarp]` : Permet de supprimer le PWarp.

</details>

<details>

<summary>🏪 Shops de joueurs</summary>

* `/finditem [Acheter/Vendre] [ID de l'item/Nom de l'item]` : Permet de rechercher, dans le monde Construction, les coffres de joueurs qui achètent ou vendent l'objet souhaité.
* `/qs create [Prix]` : Permet de transformer le coffre visé en coffre de vente pour l'objet tenu en main.
* `/qs buy` : Permet de transformer le coffre de vente visé en coffre d'achat.
* `/qs price [Prix]` : Permet de changer le prix d'un coffre d'achat ou de vente.
* `/qs item` : Permet de changer l'objet proposé dans le coffre de vente ou d'achat.
* `/qs staff add [Pseudo]` : Permet d'ajouter un joueur dans la liste des joueurs pouvant modifier les informations du coffre.
* `/qs staff del [Pseudo]` : Permet de retirer un joueur de la liste des personnes pouvant modifier les informations du coffre.
* `/qs staff list` : Affiche la liste des joueurs pouvant modifier les informations du coffre.
* `/qs setowner [Pseudo]` : Permet de modifier le propriétaire du coffre de vente ou d'achat que vous regardez.
* `/qs history` : Permet de voir l'historique des ventes réalisées sur le coffre visé.
* `/qs remove` : Permet de supprimer le coffre de vente ou d'achat que vous regardez.

</details>

<details>

<summary>🔒 Coffres privés</summary>

* `/cadenas lock` ou `/lock lock` : Permet de privatiser un coffre.
* `/cadenas unlock` : Permet de déprivatiser un coffre.
* `/cadenas add [Pseudo]` : Permet de donner à un joueur l'accès au coffre privé.
* `/cadenas remove [Pseudo]` : Permet de retirer à un joueur l'accès au coffre privé.
* `/cadenas list` : Permet de voir les joueurs ayant accès au coffre privé.
* `/cadenas open` : Permet de gérer la liste des joueurs qui peuvent ouvrir le coffre privé.

</details>

<details>

<summary>🏛️ Donjons</summary>

* `/donjon_reward` : Permet de voir le niveau requis et les récompenses d'un donjon.
* `/party create` : Permet de créer un groupe de donjon.
* `/party invite [Pseudo]` : Permet d'inviter un joueur dans le groupe de donjon.
* `/party kick [Pseudo]` : Permet de retirer un joueur du groupe de donjon.
* `/donjon [Rareté] [Nombre de places] [Prix]` : Permet de publier une annonce pour un donjon réservé.
* `/party accept [Pseudo]` : Permet d'accepter une invitation à rejoindre le groupe de donjon.
* `/party deny [Pseudo]` : Permet de refuser une invitation à rejoindre le groupe de donjon.
* `/party info` : Permet de voir les joueurs présents dans le groupe.
* `/party start` : Permet de démarrer un donjon.
* `/party tp` : Permet de se téléporter dans le donjon.
* `/party chat` : Active ou désactive le chat de groupe. Une fois activé, tous les messages sont envoyés uniquement aux membres du groupe.
* `/party leave` : Permet de quitter le donjon ou le groupe.
* `/party disband` : Permet de dissoudre un groupe de donjon.

</details>

<details>

<summary>🐾 Compagnons</summary>

* `/compagnons` ou `/pets` : Permet d’ouvrir le menu des compagnons.
* `/pokedex` : Affiche tous les compagnons présents sur le serveur.

</details>

<details>

<summary>🛠️ Services</summary>

* `/fly` : Active ou désactive le vol.
* `/forgeron` : Permet de réparer un outil ou une arme personnalisée.
* `/kit` : Accès aux kits disponibles.
* `/afk` : Permet de passer en mode AFK en toute sécurité.
* `/trash` : Permet de jeter des objets indésirables.
* `/peche` : Accès aux différentes informations concernant la pêche sur le serveur ainsi que la vente de poissons personnalisés.
* `/craft` : Ouvre l'interface d'une table de fabrication.
* `/anvil` : Ouvre l'interface d'une enclume.
* `/grindstone` : Ouvre l'interface d'une meule.
* `/stonecutter` : Ouvre l'interface d'un tailleur de pierre.
* `/smithingtable` : Ouvre l'interface d'une table de forgeron.
* `/ec` : Ouvre l'interface de votre Ender Chest.
* `/feed` : Restaure la barre de faim du joueur.
* `/condense` : Permet de regrouper des objets en blocs.
* `/furnace` : Permet de cuire l'objet tenu en main.
* `/furnace all` : Permet de cuire tous les objets compatibles de votre inventaire.
* `/xpbottle [Quantité d'expérience] [Nombre de bouteilles]` : Permet de transformer votre expérience en bouteilles.
* `/repair` : Permet de réparer un outil vanilla tenu en main.
* `/repair all` : Permet de réparer tous les objets vanilla réparables de votre inventaire.

</details>

<details>

<summary>🎭 Social et personnalisation</summary>

* `/profil [Pseudo]` ou `/p [Pseudo]` : Affiche le profil du joueur indiqué.
* `/msg [Pseudo] <Message>` ou `/m [Pseudo] <Message>` : Permet de discuter avec un joueur en message privé.
* `/r <Message>` : Permet de répondre à un joueur en message privé.
* `/ignore add [Pseudo]` : Permet d'ignorer un joueur dans le chat et dans les messages privés.
* `/ignore remove [Pseudo]` : Permet de ne plus ignorer un joueur dans le chat et dans les messages privés.
* `/tags` : Permet d’ouvrir le menu des tags disponibles et d’équiper le vôtre.
* `/nick` : Permet de changer son pseudo dans le chat.
* `/ptime` : Permet de changer l'heure locale du joueur.
* `/pweather` : Permet de changer la météo locale du joueur.
* `/cosmetics` : Permet d’accéder aux différents cosmétiques présents sur le serveur.
* `/glowing` : Permet d'ajouter/de changer l'effet de surbrillance autour de soi.
* `/option` : Permet de changer divers paramètres selon les préférences du joueur.
* `/sb` : Permet d'activer ou de désactiver le tableau de bord.

</details>

<details>

<summary>💍 Mariage</summary>

* `/marry accept` : Accepte une demande en mariage.
* `/marry decline` : Refuse une demande en mariage.
* `/marry kiss` : Permet de faire apparaître des cœurs autour des deux joueurs.
* `/marry sethome` : Permet de définir un point de téléportation commun aux deux joueurs.
* `/marry home` : Permet de se téléporter au point commun du couple.
* `/marry msg <Message>` : Permet d'envoyer un message privé à son partenaire.

</details>

<details>

<summary>📦 Autres commandes</summary>

* `/hdb` : Permet d'avoir des têtes de décoration (disponibles avec le Premium).
* `/e` : Permet d'afficher la liste des emojis disponibles (avec le Premium).
* `[i]` : Permet d'afficher un objet dans le chat (disponible avec le grade Élite).

</details>
